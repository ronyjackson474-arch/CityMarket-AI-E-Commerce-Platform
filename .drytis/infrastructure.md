# CityMarket Infrastructure

## Caddy Proxy
- PHP server at `/` (project root `/workspace`, template `laravel` → serves `/workspace/public`)
- PHP version: 8.4

## Background Services
- None required for Phase 1 (Laravel is served by Caddy PHP-FPM directly).
- Phase 2+ may add: queue worker (`php artisan queue:work`), scheduler (`php artisan schedule:work`).

## Environment Variables
Located in `/workspace/.env` (managed via backend env_keys, never edited directly):

| Key | Tag / Value |
|-----|-------------|
| APP_NAME | project_name |
| APP_ENV | app_env |
| APP_DEBUG | app_debug |
| APP_URL | https://{{DOMAIN}} |
| APP_KEY | static (generated by artisan, guarded) |
| DB_CONNECTION | mysql |
| DB_HOST | database_host |
| DB_PORT | database_port |
| DB_DATABASE | database_name |
| DB_USERNAME | database_user |
| DB_PASSWORD | database_password (secret) |
| OPENAI_API_KEY | static (minted via create_openai_api_key, secret) |
| OPENAI_BASE_URL | static (from create_openai_api_key) |
| AI_MODEL | static (gpt-4o-mini default) |

## Ports
- No local port needed (Caddy serves PHP-FPM directly).
- API and web both served via the same Caddy PHP route at `/`.

## Setup Script
Runs on every deploy/container start:
1. `composer install --no-interaction --prefer-dist --optimize-autoloader`
2. `npm ci && npm run build` (Tailwind/Vite assets)
3. `php artisan migrate --force`
4. `php artisan db:seed --force` (idempotent seeders)
5. `php artisan storage:link` (guarded)
6. `php artisan config:cache && php artisan route:cache && php artisan view:cache`
